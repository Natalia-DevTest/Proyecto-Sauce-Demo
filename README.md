# Proyecto Sauce Demo

Este proyecto tiene como objetivo poner en práctica los conocimientos adquiridos en clase mediante la automatización de pruebas sobre la plataforma **[Sauce Demo](https://www.saucedemo.com/)**.

A través de este repositorio, se implementan scripts y suites de prueba para validar los diferentes flujos del sitio web, asegurando la estabilidad y el correcto funcionamiento de la interfaz de usuario y la lógica de negocio.

## 🚀 Objetivos del Proyecto
* **Automatización de Pruebas:** Desarrollar scripts robustos para simular la interacción del usuario en la plataforma.
* **Prácticas de QA:** Aplicar metodologías de testing y frameworks de automatización vistos en el curso.
* **Gestión de Errores:** Identificar, documentar y reportar comportamientos anómalos en el sistema.

## 📋 Reporte de Bugs
Todos los fallos, errores de interfaz (UI) y problemas de lógica encontrados durante el proceso de pruebas son documentados y gestionados de forma centralizada.
